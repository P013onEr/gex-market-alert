# GEX Market Alert

## 产品说明

这是一套运行在 Mac mini 上的期权市场结构分析和行情提醒工具。系统通过分析
做市商可能进行的期权对冲行为，结合 GEX（Gamma Exposure）和 OI（未平仓合约）
数据，识别市场中的关键支撑区域、阻力区域，以及流动性密集或稀疏的位置。

它适合用于观察短线交易机会、盘中价格变化和流动性空隙，帮助交易者减少无效
盯盘，在价格接近关键区域时及时查看行情。

> 本工具提供市场结构参考和提醒，不承诺预测涨跌，也不代替交易者作出交易决定。

## 可以自定义什么

| 可调整内容 | 可以实现的效果 |
|---|---|
| 关注的标的 | 只观察指定的股票或 ETF |
| 观察的到期范围 | 选择当天、近期期权或更远到期期权的数据 |
| 关键区域类型 | 选择支撑、阻力、GEX 集中区、OI 集中区或流动性空隙 |
| 接近距离 | 例如距离关键位置 0.5% 时提醒 |
| 数据刷新频率 | 在及时性和提醒数量之间取得平衡 |
| 重复提醒间隔 | 同一位置触发后，在指定时间内不重复提醒 |
| 提醒渠道 | 电脑通知、手机消息、邮件或已接入的消息工具 |
| 提醒时间 | 只在指定交易时段提醒，收盘后自动停止 |
| 提醒内容 | 显示标的、当前价格、参考区域、距离和触发原因 |
| 多标的管理 | 每个标的可以使用不同的提醒条件 |

## 使用后可以得到什么

当价格接近关键区域时，会收到类似下面的提醒：

```text
SPY 价格接近 GEX 参考压力区
当前价格：待显示
参考位置：待显示
距离：待显示
区域信息：GEX / OI 关键区域
提醒原因：进入预警范围
```

可以按照交易习惯选择：

- 只提醒接近压力位；
- 只提醒接近支撑位；
- 支撑位和压力位都提醒；
- 观察 GEX 或 OI 较集中的执行价区域；
- 观察流动性较弱、价格可能加速运行的区域；
- 第一次接近时提醒，之后暂时不重复提醒；
- 价格离开后再次接近时重新提醒；
- 同时观察多个标的，但每个标的单独设置规则。

## 使用方式

### 初次设置

1. 准备一台可以长期运行的 Mac mini。
2. 配置行情账户和消息提醒方式。
3. 完成一次安装和设置。
4. 先用一个标的测试提醒是否正常。
5. 测试通过后，再增加其他标的。

### 运行期间

1. Mac mini 保持开机并连接网络。
2. 工具在后台运行。
3. 系统根据最新的 GEX、OI 和价格数据更新关键区域。
4. 行情接近设置的位置时发送提醒。
5. 收到提醒后打开证券软件进行进一步判断。

### 修改设置

可以随时调整关注标的、提醒范围、提醒时间和消息渠道。
修改后重新启动工具即可使用新的设置。

## 推荐的初始设置

第一次使用建议：

- 先设置 1～3 个标的；
- 先选择一种手机提醒渠道；
- 预警范围不要设置得过于敏感；
- 先观察一个交易日的提醒数量和质量；
- 设置重复提醒间隔，减少短时间内连续打扰。

## 重要说明

- 支撑位和压力位会随着最新市场数据变化，不是固定不变的价格。
- GEX 用于观察期权 Gamma 敞口及其可能带来的对冲影响。
- OI 用于观察未平仓合约在不同执行价上的分布。
- 两者结合可以辅助标记影响盘中价格运行的关键区域。
- 期权数据可能存在延迟、缺失或更新时间差异。
- 没有提醒不代表没有交易机会；收到提醒也不代表一定会反弹或突破。
- 行情账户、消息服务和 AI 服务产生的费用由使用方自行承担。
- 账户信息、密钥和 AI Token 只保存在本地 Mac mini 上。

完成 GEX/OI 数据监控、提醒渠道和 Mac mini 后台运行配置。

后续可以继续增加：

- 更多股票和 ETF；

- 每日盘前和盘后总结；

- 网页查看页面；
- 不同标的使用不同提醒规则。
