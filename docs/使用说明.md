# GEX Market Alert 使用说明

## 一句话说明

工具在 Mac mini 上后台运行，通过做市商期权对冲行为的结构分析，结合 GEX
和 OI 数据标记关键支撑区域、阻力区域以及流动性变化。

当价格接近关键区域时自动发送提醒，适合观察短线交易和盘中机会。

## 可以设置的内容

### 1. 关注哪些标的

可以添加或删除需要观察的股票、ETF 或其他支持的标的。

设置结果：只接收关注对象的分析和提醒。

### 2. 关注哪类位置

可以选择：

- 支撑位；
- 压力位；
- GEX 集中区域；
- OI 集中区域；
- 流动性空隙；
- 支撑位和压力位同时观察。

设置结果：只在关注的关键区域出现提醒。

### 3. 多近才提醒

可以设置“预警范围”。

例如设置为距离参考位置 0.5% 时提醒，价格进入这个范围后就会收到消息。
范围越大，提醒会更早；范围越小，提醒会更接近目标位置。

### 4. 多久更新一次

可以设置行情和关键区域的更新频率。

更新更频繁，提醒更及时，但消息数量和数据使用量可能增加；
更新间隔更长，提醒更安静，但可能出现一定时间差。

### 5. 多久不重复提醒

同一个位置可能在短时间内反复接近。可以设置重复提醒间隔，
避免同一件事连续收到多条消息。

### 6. 什么时候提醒

可以设置只在指定交易时间内提醒，收盘后停止发送消息。

### 7. 发到哪里

可以选择已经配置好的提醒方式，例如：

- Mac mini 本机通知；
- 手机消息；
- 邮件；
- OpenClaw 或 Hermes 已连接的消息渠道。

### 8. 每条消息显示什么

提醒内容可以包含：

- 标的名称；
- 当前价格；
- 参考支撑位或压力位；
- GEX 与 OI 关键区域；
- 当前价格与参考位置的距离；
- 触发提醒的原因；
- 提醒发生的时间。

## 一条提醒代表什么

收到“接近压力位”的提醒，表示当前价格进入了根据 GEX、OI 和市场结构识别的
压力区域预警范围。它不是买入或卖出指令，仍需结合交易策略、仓位和风险承受能力判断。

收到“接近支撑位”的提醒，含义相同，只是观察方向不同。

GEX 主要用于观察期权 Gamma 敞口及其可能带来的对冲影响；OI 用于观察未平仓
合约在不同执行价上的分布。两者结合后，可以辅助标记可能影响盘中价格运行的关键区域。

## 初次使用流程

1. 准备长期运行的 Mac mini，并保持网络连接。
2. 配置行情账户和需要使用的消息渠道。
3. 完成首次安装和设置。
4. 选择一个标的进行测试。
5. 确认手机可以正常收到提醒。
6. 再增加其他标的和个性化规则。

## 推荐的测试方式

第一次不要同时设置很多标的，也不要把提醒范围设置得太宽。
建议先运行一个交易日，观察：

- 是否能正常收到消息；
- 消息数量是否合适；
- 提醒是否过早或过晚；
- 是否需要增加重复提醒间隔。

根据观察结果调整设置，直到符合交易习惯。

## 日常维护

日常只需要：

- 保持 Mac mini 开机；
- 保持网络连接；
- 不要删除项目文件；
- 需要变更规则时修改设置并重新启动。

行情账户、消息平台或 AI 服务发生变化时，可能需要重新配置。

## 需要了解的边界

- 支撑位和压力位会随市场数据变化。
- 数据可能存在延迟或暂时中断。
- 提醒不代表价格一定反弹、突破或形成交易机会。
- 工具不会代替交易者下单。
- 应自行确认交易软件中的实时价格和账户状态。

## 后续可扩展内容

可以根据实际使用情况继续增加：

- 更多标的；
- 更多消息渠道；
- 历史提醒查询；
- 每日盘前、盘后摘要；
- 网页查看；
- 每个标的独立的提醒规则。
